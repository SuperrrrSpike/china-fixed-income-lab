# 固定收益学习清单

## 第一阶段 必须掌握

- 债券现金流、净价、全价和应计利息。
- 到期收益率与价格的反向关系。
- 麦考利久期、修正久期、凸性和 DV01。
- 国债、政策性金融债、地方债、金融债、同业存单和信用债。
- 收益率曲线、期限利差、平行移位、陡峭化和扁平化。
- 一级发行的招标标的、单一价格、修正多重价格、承销和分销。
- 二级现券的买入收益率、卖出收益率、净价报价和质押式回购。

## 第二阶段 工作能力

- 使用 Excel 透视表、XLOOKUP、筛选和条件格式整理发行信息。
- 使用 pandas 完成数据清洗、日期处理、分组计算和多表导出。
- 阅读央行公开市场操作、收益率曲线和主要宏观数据。
- 用三句话解释当天债市：发生了什么、为什么、需要关注什么。
- 对每个数值保留来源、日期、单位和复核状态。

## 第三阶段 项目扩展

- 关键期限久期与组合 DV01。
- Carry and Roll-down 分解。
- 信用利差和等级迁移。
- 回购资金成本与杠杆收益。
- PCA 曲线因子和历史情景回放。

面试前不必先做复杂利率模型。应优先保证基础计算正确、业务流程清楚、报告可以复核，并能够现场解释代码中的每个指标。
