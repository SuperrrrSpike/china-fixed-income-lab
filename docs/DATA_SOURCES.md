# 数据来源与使用边界

## 已接入：CCDC/ChinaBond 官方国债收益率曲线

- 发布机构：中央国债登记结算有限责任公司（CCDC）。
- 数据产品：中债国债收益率曲线（到期）年度标准期限文件。
- 官方入口：https://yield.chinabond.com.cn/
- 项目用途：收益率曲线、日度 BP 变化、期限利差、债券定价和情景分析。
- 可靠性：一级来源，官方页面说明曲线基于银行间和交易所报价、成交价及结算价等信息编制，每个工作日日终发布。
- 工程处理：原始 XLSX 只缓存到本机或 Lexar，不提交 Git；标准化结果保留来源 URL、原始文件 SHA-256、抓取时间和 `official_primary` 标记。
- 使用边界：本项目用于学习、研究和求职展示，不把官方原始文件重新打包发布，也不将数据用于商业产品、基准或衍生产品。需要商业使用时应向数据权利方申请授权。

## 推荐下一阶段接入

| 数据 | 官方来源 | 适用模块 | 接入判断 |
| --- | --- | --- | --- |
| 国债发行及招标结果 | 财政部国库司国债业务公告 | 一级发行跟踪 | 官方但为半结构化公告，应保存公告 URL 并人工复核解析结果 |
| 逆回购、MLF 等公开市场操作 | 中国人民银行公开市场业务交易公告 | 资金面晨报 | 官方公告，可提取期限、利率、投标量和中标量 |
| Shibor、DR、回购定盘利率 | 中国外汇交易中心/全国银行间同业拆借中心 | 资金利率与流动性 | 官方基准，优先使用公开下载或正式数据服务 |
| 银行间债券收益率曲线及估值 | 中国外汇交易中心 | 信用利差和估值 | 数据质量高，但完整接口属于正式数据服务，不使用未公开网页接口冒充稳定 API |

## 备用与演示数据

- AKShare：只作为网络备用适配器，来源和字段可能随上游变化，不能标记为官方原始数据。
- `data/sample_*.csv`：完全合成，只用于自动测试和断网演示。
- 大模型：只处理新闻分类和文字草稿，不生成、补齐或修改市场数值。

## 数据质量规则

1. 每条生产数据必须有来源名称和来源 URL。
2. 原始文件与标准化表分开保存，原始文件不可在清洗时覆盖。
3. 对日期、期限、收益率、重复键和空区间进行失败即停止的校验。
4. 插值结果必须显式标记；不允许对期限范围之外的数据外推。
5. 报告发布前人工核对最新日期、单位、关键数值和公告原文。
