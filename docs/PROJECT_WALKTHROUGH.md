# 项目讲解与面试准备

## 一分钟介绍

这个项目面向证券销售交易实习场景，解决两个问题：第一，把收益率曲线、一级发行和市场事件整理成每天可复核的债券晨报；第二，对固定利率债进行净价、全价、到期收益率、久期、凸性和 DV01 计算，并模拟不同收益率曲线情景下的价格损益。

系统默认读取 CCDC/ChinaBond 官方年度标准期限文件，AKShare 只作为备用，同时提供明确标注的合成示例数据，确保断网时仍可演示。所有市场数值由确定性代码计算，大模型只参与新闻分类和文字初稿，不允许覆盖结构化数值。

## 数据流

```text
ChinaBond 官方 XLSX / AKShare 备用 / 合成 CSV
    ↓
原始文件缓存、来源记录、字段校验与长表标准化
    ↓
收益率变化、期限利差、定价与风险指标
    ↓
晨报 Markdown / Excel / Streamlit 看板
    ↓
人工复核来源、单位和结论
```

## 模块说明

### data.py

负责下载和解析 ChinaBond 官方年度文件、读取离线数据并调用 AKShare 备用源。官方文件存在工作表范围被错误声明为 `A1` 的问题，解析器会先重新计算范围，再校验字段、重复值、期限和收益率区间。每条官方记录保留来源 URL、抓取时间和 `official_primary` 状态。备用曲线缺少 2 年期字段时，系统只在已有期限范围内线性插值，并在报告中用星号标记。

### yield_curve.py

把宽表曲线转换成统一的长表：日期、曲线名称、期限、收益率和来源。分析层在此基础上计算日度 BP 变化、期限利差，并生成平行移位、陡峭化和扁平化三类情景。

### bond.py

先根据票面利率、付息频率和到期日生成现金流，再使用到期收益率折现：

```text
全价 = Σ 现金流 / (1 + y / m)^(m × t)
净价 = 全价 - 应计利息
```

麦考利久期是现金流现值时间的加权平均；修正久期用于近似价格对收益率的一阶敏感度；凸性补充二阶影响；DV01 使用收益率上下各变动 1BP 的中心差分计算。

### issuance.py

校验并标准化发行日期、期限、规模、招标方式、结果收益率和状态，可筛选未来七日待发行债券并按品种汇总规模。

### news.py

默认使用可解释的关键词规则分类。配置 OpenAI 兼容接口后可以调用大模型，但输出会标记为需要人工复核，API 密钥只从环境变量读取。

### report.py

将分析结果转换成晨报和 Excel。Excel 包含收益率曲线、最新曲线、一级发行和市场事件四个工作表，并设置冻结首行、筛选和自适应列宽。

### dashboard.py

提供三个页面：市场看板、债券风险和晨报导出。看板可以切换离线数据与 AKShare 在线数据，也可以调节曲线冲击类型和 BP 幅度。

## 演示顺序

1. 运行 `fixed-income-lab demo`，展示离线晨报与 Excel。
2. 运行 `fixed-income-lab fetch --start 20260901 --end 20260922`，展示官方原始文件缓存、来源追踪和关键期限数据。
3. 运行 `fixed-income-lab price`，展示净价、久期、凸性和 DV01。
4. 启动 Streamlit，切换三类曲线情景并查看价格损益。
5. 运行 `pytest`，展示计算、数据解析和界面共 28 项自动测试。

## 面试常见问题

### 为什么不让大模型直接计算收益率和 DV01

金融数值必须可重复、可测试和可追溯。大模型适合处理非结构化文本，但不适合作为定价引擎。项目让大模型只负责分类和草稿，核心数值由 Python 函数计算并由测试覆盖。

### 2 年期数据不存在怎么办

系统不会伪造原始字段。若 2 年期限位于已有曲线范围内，则使用相邻期限线性插值，并在输出中标记；如果目标期限位于曲线范围之外，则直接报错，不做外推。

### DV01 是什么

DV01 表示收益率变动 1BP 时债券价格的近似变化金额。正久期债券的收益率上升时价格下降，因此项目用上下 1BP 的中心差分，将 DV01 输出为正的风险绝对值。

### 当前模型有哪些限制

- 定价使用 ACT/365 近似，没有覆盖所有中国债券日计数和节假日约定。
- 曲线情景是教学与演示版本，没有做多曲线贴现或关键期限久期分解。
- 一级发行目前支持结构化录入和跟踪，财政部公告仍是半结构化文本，尚未自动覆盖所有发行人。
- 新闻分类仍需要人工核对来源、时点和影响方向。
