# 固定收益数据流水线实施计划

## 完成条件

- `fixed-income-lab pipeline` 可运行演示、官方和 AKShare 数据源。
- 质量检查失败时不发布最终目录。
- 成功运行生成标准化数据、晨报、Excel、质量报告和运行清单。
- 清单中的文件哈希可复算一致。
- 全部单元测试通过，CI 执行离线端到端冒烟测试。

## 步骤一：数据质量门禁

1. 新增 `tests/test_quality.py`，覆盖有效数据、缺字段、重复键、异常数值和官方来源元数据缺失。
2. 运行测试并确认因模块不存在而失败。
3. 新增 `src/fixed_income_lab/quality.py`，实现纯函数校验和 JSON 可序列化摘要。
4. 运行质量测试及现有测试。

## 步骤二：原子流水线

1. 新增 `tests/test_pipeline.py`，覆盖完整演示运行、产物清单哈希和失败清理。
2. 新增 `src/fixed_income_lab/pipeline.py`，复用现有来源与报告模块。
3. 在目标目录内使用临时目录，成功后原子发布；异常时清理。
4. 输出标准化 CSV、质量报告和不含敏感信息的清单。

## 步骤三：命令行与 CI

1. 为 `cli.py` 增加 `pipeline` 子命令及条件参数校验。
2. 增加命令行测试，确认演示模式成功、官方模式缺日期时失败。
3. 更新 CI，在单元测试后运行离线流水线并检查清单文件存在。
4. 更新 README 的命令、产物和失败语义。

## 步骤四：验收与发布

1. 运行完整 pytest、编译检查和离线端到端命令。
2. 使用本机缓存或网络运行官方流水线，核对数据状态和来源元数据。
3. 扫描密钥、大文件和意外生成物。
4. 提交、推送并等待 GitHub Actions 完成。
5. 记录实际验证结果与仍存在的数据边界。

## 下一批

固定收益项目通过后，进入仓储项目：增加训练/近期窗口特征漂移报告、数据指纹对比、模型性能回归阈值和 CI 测试。
